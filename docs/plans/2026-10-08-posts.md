**Spiked beforehand** in a scratch copy of `main`:
- **Tests:** all code below passes its 11 tests.
- **Checks:** Biome and `tsc` are clean, and `next build` exports `out/posts/index.html` and `out/posts/shipping-image-datasets-off-a-mac/index.html`.
- **Browser:** the article column measures 640px, the body is Lausanne at 16px on a 28px line height, inline and block code use NB International Pro Mono, the cheat sheet scrolls inside its block, and highlighting switches between GitHub light and dark.
- **Changes the spike forced:**
  - **Dates:** `formatPostDate` uses a fixed month list, because `Intl` with `en-GB` abbreviates September as `SEPT`. The spec's "formatted in UTC" holds trivially, since no `Date` is involved.
  - **Links:** the list links to `/posts/<slug>`, without the trailing slash. Next's `trailingSlash: true` writes `/posts/<slug>/` into the built HTML, and that's how `Navigation` links already work.
  - **Biome:** the detail page needs a reasoned `biome-ignore` for `noDangerouslySetInnerHtml`, which Biome's recommended rules include.

## Global constraints

- **Static export:** everything renders at build time. `lib/posts.ts` only runs in server components and `generateStaticParams`, and no Markdown or Shiki code reaches the browser.
- **Colours are tokens only.** The typography plugin's colours are pointed at the tokens.
- **Before each commit:** run `npm run lint`, `npm run typecheck`, `npm test` and `npm run build`.
- **CI:** it runs on every push to the pull request; wait for it before the next task.
- **Commit messages:** conventional, with a lowercase subject, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review focus

1. **A broken post** (missing field, bad date) must fail the build with the file name. It must not render a half-empty page. Pinned by Task 1's tests.
2. **An unknown slug,** for example `/posts/nope/`: there is no file to serve, so S3 serves `404.html`. Pinned by `dynamicParams = false` in Task 2, step 5, and the build listing in step 8.
3. **Dark mode in code blocks:** the code colours must switch with the `dark` class, not with the operating system setting. Pinned by the browser check in Task 2, step 9.
4. **Long code lines** scroll inside their block and never widen the page. Pinned by Task 2, step 9.
5. **Dates near midnight or across time zones** must never shift by a day. Pinned by `formatPostDate` working on the string, not a `Date` (Task 1 test).

`lib/posts.ts`:

```ts
import fs from 'node:fs'
import path from 'node:path'

import rehypeShiki from '@shikijs/rehype'
import matter from 'gray-matter'
import rehypeStringify from 'rehype-stringify'
import remarkGfm from 'remark-gfm'
import remarkParse from 'remark-parse'
import remarkRehype from 'remark-rehype'
import { unified } from 'unified'

export type PostMeta = {
  slug: string
  title: string
  date: string
  description: string
}
export type Post = PostMeta & { html: string }

const POSTS_DIR = path.join(process.cwd(), 'content', 'posts')
const DATE = /^\d{4}-\d{2}-\d{2}$/

// YAML reads an unquoted 2026-10-08 as a Date; keep dates as YYYY-MM-DD strings
const toDateString = (value: unknown) =>
  value instanceof Date ? value.toISOString().slice(0, 10) : value

const readPost = (dir: string, file: string) => {
  const { data, content } = matter(
    fs.readFileSync(path.join(dir, file), 'utf8'),
  )
  const date = toDateString(data.date)
  for (const field of ['title', 'description'] as const) {
    if (typeof data[field] !== 'string' || !data[field].trim()) {
      throw new Error(`${file}: front matter needs a "${field}"`)
    }
  }
  if (
    typeof date !== 'string' ||
    !DATE.test(date) ||
    Number.isNaN(Date.parse(date))
  ) {
    throw new Error(`${file}: front matter needs a "date" as YYYY-MM-DD`)
  }
  const meta: PostMeta = {
    slug: file.replace(/\.md$/, ''),
    title: data.title,
    date,
    description: data.description,
  }
  return { meta, content }
}

export const getPosts = (dir = POSTS_DIR): PostMeta[] =>
  fs
    .readdirSync(dir)
    .filter((f) => f.endsWith('.md'))
    .map((f) => readPost(dir, f).meta)
    .sort((a, b) => b.date.localeCompare(a.date))

export const getPost = async (slug: string, dir = POSTS_DIR): Promise<Post> => {
  const { meta, content } = readPost(dir, `${slug}.md`)
  const file = await unified()
    .use(remarkParse)
    .use(remarkGfm)
    .use(remarkRehype)
    .use(rehypeShiki, {
      themes: { light: 'github-light', dark: 'github-dark' },
      defaultColor: false,
    })
    .use(rehypeStringify)
    .process(content)
  return { ...meta, html: String(file) }
}

const MONTHS = [
  'JAN',
  'FEB',
  'MAR',
  'APR',
  'MAY',
  'JUN',
  'JUL',
  'AUG',
  'SEP',
  'OCT',
  'NOV',
  'DEC',
]

// Built by hand: Intl abbreviates September as "Sept" in en-GB, and parsing
// the date would bring time zones into it
export const formatPostDate = (date: string) => {
  const [year, month, day] = date.split('-')
  return `${day} ${MONTHS[Number(month) - 1]} ${year}`
}
```

- [ ] **Step 1: Let the main area scroll on wider screens**

In `app/layout.tsx`, change `<main className="flex-auto">` to `<main className="flex-auto md:min-h-0 md:overflow-y-auto">`.
